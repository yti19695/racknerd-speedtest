## 自己动手做 RackNerd 速度测试：测试 IP 和完整流程

自己测不难，关键是别只看一个 ping 值就下结论。多个测评推荐的流程分五步：

1. **先 ping 测试 IP 看裸延迟**。下面三个 IP 在多份测评里数据一致：圣何塞 192.210.207.88、洛杉矶 DC-02 204.13.154.3、纽约 192.3.81.8。其他机房的建议直接查官方 Looking Glass——网上流传的机房 IP 清单互相抄来抄去，好几份已经对不上机房了。
2. **speedtest-cli 手动指定国内节点**。它默认选最近的节点，对国内速度参考价值有限；更严谨的做法是用 iperf3 直接对打。
3. **wget 一个 1GB 测试文件看真实下载**。实际拉文件比 Speedtest 数字更接近日常体验。
4. **用 BestTrace 或 mtr 跑三网回程路由**，确认走的是 163 骨干、CN2 GT 还是普通国际线路。
5. **北京时间 20:00-22:00 复测延迟和丢包**。白天各家数据都好看，晚高峰才是分水岭。

早中晚各测一轮比单次结果可靠。有些机房延迟看着低，路由绕路严重，实际体验糟糕，traceroute 一眼就能看出来。
